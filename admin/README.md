# Модуль admin

Веб-админка: персоны, воспоминания, чаты, промпт, эмоции, настройки, модераторы.
Отдельный процесс и отдельный jar, порт 8081.

## Сборка и запуск

Из корня репозитория:

```
mvn -pl admin -am package
java -jar admin/target/telegram-bot-admin-1.0.jar
```

Админка не подключается к Telegram: у неё нет токена, бота и уведомлений. Входящих обновлений и исходящих сообщений нет.

## Переменные окружения

| Переменная | Значение |
|---|---|
| `BOT_DB_URL` | JDBC-URL базы |
| `BOT_DB_USER` | роль `admin_user` |
| `BOT_DB_PASSWORD` | пароль роли |
| `BOT_ADMIN_PASSWORD` | пароль владельца; без него страницы отвечают 404 |
| `BOT_ADMIN_PORT` | порт, по умолчанию `8081` |
| `BOT_ADMIN_BIND` | адрес; локально `127.0.0.1`, на сервере `0.0.0.0` за правилом файрвола |

`BOT_TOKEN` и `BOT_AI_KEY_*` админке не нужны. Наличие ключей она берёт из `ai.provider_key_status`.

Удалённое воспоминание возвращается в разделе «Воспоминания»: фильтр «удалённые», кнопка «Восстановить». Журнала изменений и кнопки «Вернуть» больше нет.
