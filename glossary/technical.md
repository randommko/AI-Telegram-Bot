# Технический глоссарий

Термины процесса OpenSpec и инфраструктуры проекта. Предметные термины — в `business.md`.

| Термин | Определение | Когда использовать | Не путать с |
| --- | --- | --- | --- |
| Возможность (capability) | Группа требований в `openspec/specs/<capability>/spec.md`, описывающая одно поведение системы. | Когда говорите, какую спеку меняет изменение. | Изменение — временная папка с планом правок. |
| Изменение (change) | Папка `openspec/changes/<kebab-имя>` с proposal, дельтой, design и tasks. | Когда речь о конкретной работе и её артефактах. | Возможность — постоянная спека. |
| Дельта спеки | Файл изменения с блоками ADDED / MODIFIED / REMOVED Requirements. | Когда речь о правке требований. | Основная спека — итог после архивации. |
| Архивация | Перенос изменения в `openspec/changes/archive/YYYY-MM-DD-<имя>` с пересборкой основной спеки. | Когда изменение выкачено и проверено. | Удаление — архивы хранятся. |
| ADR | Запись об архитектурном решении в `openspec/adr/`, с контекстом, вариантами и последствиями. | Когда решение долговечно и влияет на структуру. | Design изменения — план конкретной правки. |
| Ссылка на глоссарий | Файл `<артефакт>-glossary-reference.md` рядом с артефактом: какие термины глоссария в нём использованы. | Когда создаёте или правите артефакт. | Сам глоссарий — таблица терминов. |
| Long polling | Режим получения обновлений Telegram: бот сам опрашивает `getUpdates`. | Когда речь о том, как бот получает сообщения. | Webhook — обратный режим, проектом не используется. |
| Callback | Нажатие inline-кнопки под сообщением; приходит апдейтом `callback_query`. | Когда речь о кнопках под ответами. | Обычное сообщение в чате. |
| Реплай | Ответ с цитатой исходного сообщения. | Когда ответ должен быть привязан к вопросу. | Упоминание через `@` — другой механизм. |
| Миграция | SQL-файл в `migrations/`, который накатывается на сервере. | Когда меняется схема или данные. | Правка кода, которая читает таблицу. |
| Грант | Право роли PostgreSQL на объект базы. | Когда роль не может читать или писать таблицу. | Роль — сама учётная запись базы. |
| Деплой | Push в `main`, запускающий `Deploy bot` или `Deploy admin` по своим фильтрам путей. | Когда говорите о выкатке в прод. | Сборка — локальный `mvn package`. |
| Модуль | Maven-модуль проекта: `core`, `bot`, `admin`. | Когда речь о том, где лежит код. | Возможность — единица спек, не кода. |
| Проход чтения | Фоновый разбор пачки новых сообщений чата: один запрос к модели, из которого берутся 0–2 реакции. Запускается по тишине или по заполнению пула. | Когда речь о том, как бот решает, на что реагировать. | Анализ памяти — другой фоновый проход, он извлекает факты. |
