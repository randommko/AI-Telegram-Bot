# Proposal

## Why

Команда `/clear` стирает историю AI чата сразу и необратимо: `DELETE FROM ai_messages WHERE chat_id = ?` без возможности отката. Выполнить её может любой участник группы одной строкой, случайное нажатие или шутка стоит всей памяти AI. Кроме того, команды нет ни в `README.md`, ни в `/bot_info`, поэтому о ней знают только те, кто читал код.

## What Changes

- `/clear` больше не удаляет историю сразу: сначала присылает вопрос с inline-кнопками «Да» / «Отмена».
- «Да» — сброс и редактирование сообщения в «Память обнулена, забыто N сообщений», где N — размер истории на момент команды.
- «Отмена» — сообщение редактируется в «Отменено», история и счётчик сбросов не меняются.
- Нажать кнопку может только автор команды; чужое нажатие получает всплывающее уведомление и ничего не меняет.
- Две паузы `Thread.sleep(1000)` в обработчике убираются — вместо них редактирование одного сообщения.
- `/clear` добавляется в `README.md` и в текст `/bot_info`.

Поведение сброса (что именно удаляется, что сохраняется, счётчик) не меняется, добавляется только шаг подтверждения.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `ai-chat-memory`: требование «Сброс памяти AI для чата» дополняется подтверждением — сброс выполняется только после явного согласия автора команды, и отказ либо чужое нажатие историю не меняют.

## Impact

- `src/main/java/org/example/CommandDispatcher.java` — `handleAiChatHistory` вместо очистки отправляет вопрос с клавиатурой; `/clear` попадает в текст `/bot_info`.
- `src/main/java/org/example/CallbackDispatcher.java` — хендлеры кнопок подтверждения рядом с существующей картой `handlers`.
- `src/main/java/org/example/KeyboardBuilder.java` — клавиатура «Да» / «Отмена» (сейчас умеет только зодиаки).
- `MessageSender.editMessage` переиспользуется как есть; `AiService.getChatHistorySize` и `clearChatHistory` не меняются.
- `README.md` — строка про `/clear` в списке команд.
- Тесты: `CommandDispatcherTest` (команда больше не вызывает сброс), новый тест на обработку кнопок; `AiServiceTest` не затрагивается.
- Вне scope: сама очистка в БД, лимит истории, счётчик сбросов, права доступа к команде (кто вообще может её вызвать).
