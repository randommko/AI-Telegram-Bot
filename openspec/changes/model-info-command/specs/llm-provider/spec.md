# Spec Delta

## Purpose

Дополнение к спецификации провайдеров LLM для команды показа информации о модели.

## MODIFIED Requirements

### Requirement: Команда показывает стоимость модели

Система SHALL предоставлять команду `/model_info`, которая показывает стоимость модели за миллион токенов (в рублях) — входных и выходных. Команда показывает фактическую модель, которой бот ответит, и должна быть доступна всем участникам чата. Стоимость должна отображаться только для моделей, у которых она известна в каталоге.

#### Scenario: Команда показывает стоимость модели

- **WHEN** пользователь в чате с персоной или без неё вводит команду `/model_info`
- **THEN** бот отвечает информацией о текущей модели, включая стоимость входных и выходных токенов за миллион рублей, если она известна

#### Scenario: Команда не показывает стоимость для модели без данных

- **WHEN** пользователь в чате с персоной или без неё вводит команду `/model_info` и текущая модель не имеет данных о стоимости
- **THEN** бот отвечает информацией о текущей модели, но без указания стоимости токенов

#### Scenario: Команда показывает фактическую модель

- **WHEN** пользователь в чате с персоной или без неё вводит команду `/model_info`
- **THEN** бот отвечает информацией о фактической модели, которая будет использоваться для ответа, а не о настройке

#### Scenario: Команда показывает информацию о реакциях

- **WHEN** пользователь в чате с персоной или без неё вводит команду `/model_info`
- **THEN** бот отвечает информацией о модели, используемой для реакций (основная или собственная)
