# Spec Delta

## MODIFIED Requirements

### Requirement: Модель выбирается из списка

Система SHALL предлагать модель выпадающим списком известных клиенту значений, сгруппированных по поставщику, и MUST отклонять сохранение значения, которого в списке нет, показывая ошибку у поля.

#### Scenario: Выбор модели

- **WHEN** администратор открывает список моделей
- **THEN** в нём есть известные клиенту значения, сгруппированные по поставщику, и текущая модель выбрана

#### Scenario: Значение вне списка

- **WHEN** в запросе пришло имя модели, которого нет в списке
- **THEN** форма возвращается с ошибкой у поля модели, а сохранённое значение не меняется

#### Scenario: Подсказка об отсутствии ключа

- **WHEN** администратор открывает список моделей
- **THEN** у поставщика без ключа в окружении видна пометка с именем недостающей переменной окружения
