# Spec Delta

## MODIFIED Requirements

### Requirement: Связь «модератор — чат» выдаёт и отзывает владелец

Система SHALL показывать в строке модератора выпадающий список всех известных чатов с галочками и MUST выдавать или отзывать связь одной кнопкой «Сохранить» на строку: отмеченные чаты выдаются, снятые — отзываются, сама учётка не удаляется.

#### Scenario: Выдача чата

- **WHEN** владелец отметил чат в списке и сохранил строку модератора
- **THEN** модератор видит этот чат и персону этого чата в следующий вход

#### Scenario: Отзыв чата

- **WHEN** владелец снял галочку с чата и сохранил строку
- **THEN** модератор больше не видит ни этот чат, ни его персону, а учётка остаётся

#### Scenario: Одна кнопка на строку

- **WHEN** владелец изменил и чаты, и персоны в одной строке
- **THEN** одно нажатие «Сохранить» применяет оба набора

### Requirement: Владелец выдаёт доступ к персонам из раздела «Модераторы»

Система SHALL показывать в строке модератора выпадающий список всех персон с источником доступа (чат, создал сам, выдан владельцем) и MUST позволять владельцу выдать или отозвать доступ одной кнопкой «Сохранить» на строку. Галочка MUST быть только у выдачи; персоны, доступные по авторству или через чат, MUST быть подписями и MUST NOT отзываться из этой формы.

#### Scenario: Выдача доступа

- **WHEN** владелец отметил персону и сохранил строку модератора
- **THEN** персона появляется у модератора с пометкой «выдан» и становится доступна для правки

#### Scenario: Отзыв доступа

- **WHEN** владелец снял галочку с выданной персоны и сохранил строку
- **THEN** модератор теряет правку персоны, а просмотр остаётся, только если у него есть один из её чатов

#### Scenario: Выдача уже выданного

- **WHEN** владелец повторно сохраняет строку с отмеченной персоной, доступ к которой уже выдан
- **THEN** доступ не дублируется, список не меняется

#### Scenario: Авторство и чат не отзываются

- **WHEN** у персоны источник «создал сам» или «через чат»
- **THEN** в списке она показана подписью без галочки, и сохранение строки не меняет этот доступ
