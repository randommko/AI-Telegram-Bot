# Proposal

## Why

Проход чтения (реакции) отправляет запросы с жёстко зашитым бюджетом в 500 токенов. У рассуждающих моделей polza рассуждения списываются из того же лимита: 2026-11-10 в живом журнале видно, как `z-ai/glm-5.3-flash` потратила все 500 токенов на рассуждения — ответ пуст, пачка реакций молча пропущена. Изменение polza-provider подняло до 4096 только бюджеты ответа и плана; бюджет реакций — третий, и он остался под тем же ударом. Владелец хочет управлять размером из админки, как остальными бюджетами.

## What Changes

- Появляется настройка **«лимит токенов прохода» `aiReactionMaxTokens`** (1..8192, по умолчанию 2000) на вкладке «Реакции», рядом с размером пула и паузой тишины.
- Проход чтения читает настройку **на каждый проход** — сохранённое значение действует без перезапуска; прежняя константа 500 становится запасным значением при пустой или некорректной настройке.
- База: новая строка настроек — миграция для живой базы, начальное значение для чистой базы.
- В основной спеке реакций появляется требование о настраиваемом бюджете; вкладка «Реакции» в спеке админки получает новое поле.
- Раздел «Вики» и README обновляются вместе с настройкой.

### Вне объёма

- Отключение или понижение рассуждений на уровне отдельной модели.
- Смена модели реакций по умолчанию.
- Бюджеты ответа, плана и анализа памяти — они уже подняты polza-provider или достаточны.
- Автоматический накат миграции: выполняется на сервере вручную, как остальные.

## Capabilities

### New Capabilities

Нет: изменение расширяет существующие возможности, а не вводит новую.

### Modified Capabilities

- `message-reactions`: бюджет запроса прохода чтения становится настройкой, читаемой на каждый проход, с запасным значением по умолчанию.
- `admin-console`: вкладка «Реакции» получает поле лимита токенов прохода; правила сохранения одной кнопкой и применения без перезапуска не меняются.

## Impact

- Модуль `core`: константа ключа настройки; модуль `bot`: проход читает настройку; свои тесты.
- Модуль `admin`: поле на вкладке «Реакции», диапазон в валидаторе; свои тесты.
- База: строка в seed-миграции и новая идемпотентная миграция.
- Документация: README (перечень настроек) и раздел «Вики» про проход реакций.
- Проверка: живой проход реакций на polza-модели с рассуждениями больше не пустеет.
