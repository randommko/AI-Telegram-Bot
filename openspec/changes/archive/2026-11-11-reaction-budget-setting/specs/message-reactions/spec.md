# Spec Delta

## ADDED Requirements

### Requirement: Бюджет запроса прохода задаётся настройкой

Система SHALL брать потолок выходных токенов запроса прохода чтения из настройки и MUST читать её на каждый проход, так что сохранённое значение действует без перезапуска бота. Отсутствующее или некорректное значение настройки SHALL означать запасное значение по умолчанию.

#### Scenario: Настройка применена без перезапуска

- **WHEN** администратор сохранил новый лимит токенов прохода
- **THEN** следующий проход отправляет запрос к модели с новым потолком

#### Scenario: Настройка пуста или некорректна

- **WHEN** настройка отсутствует или содержит нечисловое значение
- **THEN** проход использует запасное значение по умолчанию
