# Spec Delta

## REMOVED Requirements

### Requirement: Изменения админки пишутся в журнал

**Reason**: Журнал изменений удалён: админкой пользуется один владелец, аудит правок и откат не нужны, а вместе с журналом исчезает обратная зависимость домена от админки.

**Migration**: Записи об изменениях больше не создаются. Следы правки остаются только в логах приложения.

### Requirement: Журнал показывает кто и что менял

**Reason**: Раздел истории удалён из карточек персоны и воспоминания вместе с журналом.

**Migration**: Замены нет; история изменений объекта не показывается.

### Requirement: Значения персоны возвращаются из журнала

**Reason**: Кнопка «Вернуть» удалена вместе с журналом, потому что откатом владелец не пользовался.

**Migration**: Замены нет; прежние значения полей персоны не восстанавливаются из интерфейса.

### Requirement: Удалённое воспоминание возвращается из журнала

**Reason**: Возврат удалённого воспоминания больше не опирается на запись журнала; требование заменено восстановлением из списка «удалённые» в спеке `persona-memory`.

**Migration**: Использовать требование «Удалённое воспоминание скрывается, но остаётся восстановимым» из `persona-memory`; запись возвращается по своему `id` и `deleted_at`.

### Requirement: Журнал персоны ограничен по объёму

**Reason**: Журнал удалён, поэтому ограничивать объём записей нечего.

**Migration**: Замены нет; таблица `admin_changes` в новые схемы не переносится.
