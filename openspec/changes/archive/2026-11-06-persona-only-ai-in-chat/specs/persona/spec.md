# Spec Delta

## MODIFIED Requirements

### Requirement: Алиасы обращения принадлежат персоне

Система SHALL брать имена, по которым персона откликается, из алиасов персоны этого чата, и MUST NOT распознавать обращение по имени в чате без персоны.

#### Scenario: Новый алиас

- **WHEN** к персоне чата добавлен алиас
- **THEN** сообщение с этим словом в качестве обращения вызывает ответ персоны

#### Scenario: Удалённый алиас

- **WHEN** алиас удалён у персоны чата
- **THEN** сообщение с этим словом больше не считается обращением, и бот только сохраняет его в историю

#### Scenario: Имя персоны в чате без персоны

- **WHEN** в чат без персоны приходит сообщение без слэша, содержащее имя персоны
- **THEN** бот не обращается к AI и только сохраняет сообщение в историю

### Requirement: Чат без персоны сохраняет прежнее поведение

Система SHALL продолжать отвечать в чате без персоны по прежним правилам: системный промпт из настроек или дефолтный, слэш-команды `/ai`, `/ии`, `/аи` доступны только в чате без персоны.

#### Scenario: Промпт из настроек

- **WHEN** в чат без персоны приходит запрос к AI
- **THEN** системным промптом становится `aiPromtContext`, а при его отсутствии — дефолтный промпт

#### Scenario: Слэш-команда в чате без персоны

- **WHEN** в чат без персоны приходит `/ai вопрос`
- **THEN** бот отправляет вопрос AI и отвечает в тот же чат

### Requirement: Алиасы не конфликтуют с командами и другими персонами

Система SHALL принимать алиас только как одно слово, MUST отклонять алиас, совпадающий с командой бота, и MUST отклонять алиас, который без учёта регистра уже занят другой персоной.

#### Scenario: Алиас совпадает с командой

- **WHEN** администратор указал алиас `clear` или `summary`
- **THEN** форма возвращается с ошибкой, называющей конфликтующую команду

#### Scenario: Алиас занят другой персоной

- **WHEN** администратор указал алиас, который уже есть у другой персоны в другом регистре
- **THEN** форма возвращается с ошибкой о занятом алиасе

#### Scenario: Имя-обращение персоны

- **WHEN** администратор указал алиас `юра`
- **THEN** алиас принимается как обычный: команды с таким именем больше нет, а обращение идёт по алиасу персоны

#### Scenario: Алиас из нескольких слов

- **WHEN** администратор указал алиас с пробелом или знаком препинания
- **THEN** форма возвращается с ошибкой о формате алиаса
