# Proposal

## Why

Админка выросла стихийно: все настройки лежат в одной длинной форме из пяти групп, рядом с полями нет пояснений, а стартовая страница `/admin` — пустая заглушка «Обзор». Из-за этого непонятно, что делает параметр и когда он применяется: разбор «почему гнев 9 не меняет ответ» занял отдельный круг только потому, что смысл `base_value` и текущего значения нигде не был описан.

## What Changes

- Стартовая страница админки — «Настройки»: `/admin` ведёт туда, «Обзор» убирается из меню.
- «Настройки» делятся на пять вкладок: **Модель** (модель, температура, лимит токенов, история), **Память** (размер памяти в промпте, порог анализа), **Промты** (общий промпт), **Шаблоны** (вход и выход персоны), **Уведомления** (получатель сообщения о запуске).
- Модель выбирается выпадающим списком из известных клиенту значений; значение по-прежнему проверяется при сохранении.
- **BREAKING**: настройка `aiPromtMyChatContext` удаляется — из формы, из констант, из выбора промпта и строкой из базы. «Синий» чат без персоны начинает пользоваться общим промптом `aiPromtContext`.
- Числовые параметры с диапазоном редактируются ползунком, а не текстовым полем; проверка диапазона на сервере остаётся.
- Рядом с каждым параметром появляется иконка (i) с описанием: тексты берутся из базы — `bot_settings.description` (недостающие заполняются), `emotions.description` для эмоций и новая таблица `persona_field_notes` для шести параметров персоны.
- Карточка персоны делится на вкладки «Общее» и «Эмоции»; эмоции выводятся в два столбца.
- В каждом разделе, где есть настройки, выводится примечание «Админка работает с живыми данными бота: правки применяются к следующему запросу, перезапуск не нужен».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `admin-console`: меняются каркас и навигация (стартовая страница, меню), структура страницы настроек (вкладки, выбор модели, ползунки) и карточка персоны (вкладки, два столбца, подсказки у полей). Требование о единственном промпте чата без персоны заменяет прежнее поведение с отдельным промптом «синего» чата.

## Impact

- `migrations/008_admin_ui.sql`: таблица `persona_field_notes`, заполнение отсутствующих `bot_settings.description`, удаление строки `aiPromtMyChatContext`.
- `src/main/resources/templates/admin/`: `layout.html` (меню, плашка, стили вкладок и всплывашек), `overview.html` (удаляется), `settings.html`, `persona-form.html`, `personas.html`.
- `src/main/java/org/example/Admin/`: `AdminController`, `AdminSettingsController`, `AdminSettingsValidator`, `AdminPersonaController`.
- `org.example.Settings.Settings`: константа `AI_CONTEXT_FOR_MY_CHAT` удаляется.
- `org.example.AiChat.PersonaService`: выбор промпта без ветки «синего» чата.
- Тесты админки и `PersonaServiceTest`.

**Вне объёма:** перенос воспоминаний в карточку персоны (отдельное изменение), удаление «Промпта анализа переписки» (отдельная задача), любое изменение ответов бота.
