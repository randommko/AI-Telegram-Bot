# Proposal

## Why

Алиасы персон сейчас уникальны **глобально**, хотя чат связан не более чем с одной персоной: двое «Юр» в разных чатах не конфликтуют при обращении, но админка не даёт их завести — `AdminPersonaValidator` отклоняет алиас, занятый другой персоной. База при этом уже разрешает совпадение: уникальный индекс построен по паре `(persona_id, lower(alias))`. То есть ограничение живёт только в проверке формы и мешает без причины (#82).

## What Changes

- **Глобальная проверка занятости алиаса снимается.** Остаются два правила: алиас — одно слово без пробелов и знаков, и алиас не совпадает с командой бота.
- **Одинаковый алиас у разных персон разрешён**: обращение разрешается по чату, а чат знает только одну персону.
- **Повтор внутри одной персоны по-прежнему невозможен**: дубли без учёта регистра отбрасываются при разборе поля, а индекс `(persona_id, lower(alias))` не даёт записать дважды.
- **Подсказка в карточке и README** перестают обещать уникальность между персонами и объясняют, почему совпадение безопасно.
- **Спека `persona`**: требование о конфликтах алиасов переписывается — из него уходит проверка занятости, добавляется сценарий с одинаковым алиасом у двух персон.

## Capabilities

### New Capabilities

Нет: правило алиасов уже описано возможностью `persona`.

### Modified Capabilities

- `persona`: требование «Алиасы не конфликтуют с командами и другими персонами» заменяется требованием без проверки занятости; сценарий «Алиас занят другой персоной» уходит, вместо него — «Одинаковый алиас у двух персон».

## Impact

- `admin/src/main/java/org/example/admin/AdminPersonaValidator.java` — убрать проверку владельца алиаса, зависимость от `PersonaRepository.aliasOwner`.
- `core/src/main/java/org/example/core/aichat/PersonaRepository.java` — удалить неиспользуемый `aliasOwner`.
- `admin/src/main/resources/templates/admin/persona-form.html` — подсказка под полем алиасов.
- `README.md` — проверки карточки персоны.
- `admin/src/test/java/org/example/admin/AdminPersonaValidatorTest.java` — вместо отказа при занятом алиасе проверяется приём.
- Миграции и база не меняются: индекс уже допускает совпадение между персонами. Бот перезапустится только из-за правки `core/` при удалении неиспользуемого метода.
