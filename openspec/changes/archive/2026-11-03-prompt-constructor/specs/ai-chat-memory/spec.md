# Spec Delta

## MODIFIED Requirements

### Requirement: Системный промпт не вытесняется лимитом

Система SHALL собирать системный промпт на каждый запрос к AI независимо от размера истории, и промпт MUST NOT учитываться в лимите сообщений. Промпт MUST NOT храниться как сообщение истории: разделы читают данные из хранилища при каждой сборке.

#### Scenario: История заполнена

- **WHEN** количество сообщений в чате достигло лимита
- **THEN** запрос к AI всё равно содержит системный промпт, собранный из разделов

#### Scenario: Промпт актуален после смены настройки

- **WHEN** значение `aiPromtContext` или шаблона раздела изменено в админке
- **THEN** следующий запрос к AI использует новое значение, а не сохранённую копию

#### Scenario: Промпт приходит из персоны

- **WHEN** к чату привязана персона с промптом
- **THEN** раздел «Персона» содержит промпт персоны, и он так же не вытесняется лимитом истории
