# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Реакция | `glossary/business.md` | Решение описывает, когда и как ставится эмодзи под сообщением. |
| Каталог эмодзи | `glossary/business.md` | Хранится в базе, рисуется строками, задаёт инструкцию модели. |
| Метка памяти | `glossary/business.md` | Признак оставлен в каталоге, но в этом изменении не ставится. |
| Проход чтения | `glossary/technical.md` | Отдельный фоновый компонент бота с запуском по тишине или пулу. |
| Персона | `glossary/business.md` | Характер и состояние передаются в контекст прохода. |
| Эмоция | `glossary/business.md` | Читается в контекст, но не меняется проходом. |
| Обида | `glossary/business.md` | Влияет на отношение к автору сообщения. |
| Память персоны | `glossary/business.md` | Не меняется проходом; метка памяти вне объёма. |
| Настройка | `glossary/business.md` | Выключатель, промпт, пул и пауза читаются на каждый проход. |
| Провайдер | `glossary/business.md` | Модель реакций может быть у другого провайдера. |
| Миграция | `glossary/technical.md` | Добавляются идентификатор сообщения, журнал, отметка и каталог. |
| Грант | `glossary/technical.md` | Новые таблицы требуют явных прав для бота и админки. |
| Модуль | `glossary/technical.md` | Правки в `core`, `bot` и `admin`. |
| Деплой | `glossary/technical.md` | Выкатываются оба приложения, функция включается после. |
