# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Реакция | `glossary/business.md` | Спека задаёт выбор и постановку эмодзи под сообщением участника. |
| Каталог эмодзи | `glossary/business.md` | Служит и белым списком, и инструкцией модели; правится на вкладке «Реакции». |
| Метка памяти | `glossary/business.md` | Признак исключает эмодзи из инструкции прохода чтения. |
| Проход чтения | `glossary/technical.md` | Основное поведение новой возможности. |
| Персона | `glossary/business.md` | Проход работает только в чате с назначенной персоной. |
| Чат | `glossary/business.md` | Отметка прочитанного и журнал ведутся по чату. |
| Участник | `glossary/business.md` | Реакции ставятся на сообщения участников. |
| Эмоция | `glossary/business.md` | Текущее состояние передаётся в контекст, но не меняется. |
| Обида | `glossary/business.md` | Влияет на отношение к автору сообщения. |
| Настройка | `glossary/business.md` | Выключатель, промпт, пул и пауза читаются на каждый проход. |
| Провайдер | `glossary/business.md` | У модели реакций может быть свой провайдер с ключом. |
| Миграция | `glossary/technical.md` | Добавляются идентификатор сообщения, журнал, отметка и каталог. |
| Возможность | `glossary/technical.md` | Вводится `message-reactions`, правятся `admin-console` и `llm-provider`. |
| Long polling | `glossary/technical.md` | Сообщения приходят тем же способом, что и раньше. |
