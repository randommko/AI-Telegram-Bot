# Spec Delta

## MODIFIED Requirements

### Requirement: Вкладка «Реакции» настраивает проход чтения

Система SHALL показывать на вкладке «Реакции» выключатель функции, промпт для определения эмодзи, размер пула сообщений, паузу тишины с последнего сообщения, лимит токенов прохода и выбор модели реакций. Верхние поля SHALL сохраняться одной кнопкой, а сохранённые значения MUST применяться без перезапуска бота.

#### Scenario: Состав вкладки

- **WHEN** администратор открывает вкладку «Реакции»
- **THEN** он видит выключатель функции, поле промпта, размер пула, паузу тишины, лимит токенов прохода, выбор модели и каталог эмодзи

#### Scenario: Сохранение верхних полей

- **WHEN** администратор изменил пул, паузу или лимит токенов и нажал сохранение
- **THEN** значения записаны, страница снова открыта на вкладке «Реакции» с подтверждением, а следующий проход использует новые значения

#### Scenario: Выключенная функция

- **WHEN** администратор снял выключатель и сохранил вкладку
- **THEN** бот не запускает проход и не обращается к модели за реакциями
