# Spec Delta

## ADDED Requirements

### Requirement: Раздел «Вики» объясняет механики бота

Система SHALL показывать раздел «Вики» с описанием работы бота простым языком: как строится ответ, персона, эмоции, обиды, память, промпт, участники чата, модель и ключи, доставка ответов, права доступа и примеры настройки. Описания SHALL быть свёрнутыми блоками, а тексты промпта по умолчанию — совпадать с текстами в коде.

#### Scenario: Модератор открывает вики

- **WHEN** вошедший модератор открывает пункт меню «Вики»
- **THEN** страница показывает свёрнутые блоки с описаниями и не требует прав владельца

#### Scenario: Тексты по умолчанию

- **WHEN** развёрнут блок «Тексты по умолчанию»
- **THEN** в нём те же тексты разделов промпта, что возвращает кнопка «вернуть по умолчанию»

#### Scenario: Страница только читает

- **WHEN** открыта страница «Вики»
- **THEN** на ней нет полей ввода и кнопок сохранения, а поведение бота не меняется
