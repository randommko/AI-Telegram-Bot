# Spec Delta

## ADDED Requirements

### Requirement: Ответ доставляется целиком

Система SHALL доставлять ответ любой длины: текст, который не влезает в одно сообщение Telegram, разбивается на части по границе предложения и отправляется по порядку. Ответ MUST сохраняться в историю одним сообщением. Сбой отправки одной части MUST NOT отменять отправку остальных.

#### Scenario: Длинный ответ

- **WHEN** модель вернула ответ длиннее лимита одного сообщения Telegram
- **THEN** бот отправляет несколько сообщений по порядку, каждое в пределах лимита, а в историю ответ попадает одной записью

#### Scenario: Короткий ответ

- **WHEN** модель вернула ответ в пределах лимита
- **THEN** бот отправляет одно сообщение, как раньше

#### Scenario: В тексте нет границы предложения

- **WHEN** ответ не содержит точек, переводов строк и других границ на всю длину лимита
- **THEN** текст режется по лимиту, и факт жёсткого разрыва пишется в лог

#### Scenario: Одна часть не отправилась

- **WHEN** Telegram отклонил отправку одной из частей
- **THEN** ошибка пишется в лог, остальные части отправляются
