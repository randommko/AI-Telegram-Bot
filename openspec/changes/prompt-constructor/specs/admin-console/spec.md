# Spec Delta

## MODIFIED Requirements

### Requirement: Каркас админки с навигацией по разделам

Система SHALL показывать в каждом разделе админки постоянное меню с переходами «Персоны», «Воспоминания», «Чаты», «Промпт», «Эмоции», «Настройки» и MUST открывать «Настройки» по адресу `/admin`, не показывая отдельной страницы обзора.

#### Scenario: Обзор после входа

- **WHEN** администратор вошёл в админку
- **THEN** страница `/admin` показывает настройки и меню из шести разделов

#### Scenario: Переход в раздел

- **WHEN** администратор выбирает раздел в меню
- **THEN** открывается страница этого раздела, а меню остаётся доступным

## ADDED Requirements

### Requirement: Раздел «Промпт» показывает шаблоны разделов

Система SHALL показывать страницу «Промпт» со списком разделов в порядке сборки, и у каждого раздела MUST быть поле шаблона со счётчиком символов рядом с бюджетом и кнопкой «вернуть по умолчанию»; для раздела персоны вместо поля MUST быть ссылка на карточку персоны, где правится её текст. Сохранённые шаблоны SHALL применяться со следующего запроса к AI без перезапуска.

#### Scenario: Список в порядке сборки

- **WHEN** администратор открывает страницу «Промпт»
- **THEN** разделы идут в том же порядке, в котором они собираются в промпт

#### Scenario: Сохранение шаблона

- **WHEN** администратор изменил шаблон раздела и сохранил
- **THEN** следующий ответ в чате строится по новому шаблону без перезапуска бота

#### Scenario: Возврат по умолчанию

- **WHEN** администратор нажал «вернуть по умолчанию» у раздела
- **THEN** в поле появляется исходный текст раздела, и он сохраняется как текущий

#### Scenario: Превышение бюджета

- **WHEN** длина шаблона превышает бюджет раздела
- **THEN** счётчик показывает превышение, а сохранение не блокируется

### Requirement: Предпросмотр собранного промпта

Система SHALL показывать предпросмотр промпта, собранного на реальных данных выбранного чата с тестовым вопросом, и MUST NOT изменять данные при предпросмотре. Пустые разделы в предпросмотре MUST отсутствовать так же, как в запросе к модели.

#### Scenario: Предпросмотр на чате с персоной

- **WHEN** администратор выбрал чат с персоной и нажал «предпросмотр»
- **THEN** он видит собранный промпт с разделами персоны, эмоций, памяти, людей и времени

#### Scenario: Предпросмотр в чате без персоны

- **WHEN** выбран чат без персоны
- **THEN** в предпросмотре нет разделов эмоций, обид и памяти, но есть техника, люди, время и формат ответа

#### Scenario: Предпросмотр ничего не меняет

- **WHEN** администратор открыл предпросмотр
- **THEN** история чата, память и настройки остаются прежними

### Requirement: Раздел «Эмоции» правит справочник и фразы

Система SHALL позволять править справочник эмоций — подпись, вес в агрессию, скорость затухания, базовое значение — и текст для каждой полосы значения. Система MUST отклонять значения вне диапазонов: шкалы 0..10, вес от -1 до 1, затухание не меньше нуля. Изменения SHALL применяться со следующего ответа без перезапуска.

#### Scenario: Правка фразы полосы

- **WHEN** администратор изменил текст фразы для полосы 5-6
- **THEN** следующий ответ с эмоцией в этой полосе использует новый текст

#### Scenario: Правка веса эмоции

- **WHEN** администратор изменил вес эмоции в агрессию
- **THEN** уровень агрессии следующего ответа считается по новому весу

#### Scenario: Значение вне диапазона

- **WHEN** администратор ввёл вес 2 или базовое значение 11
- **THEN** форма показывает ошибку у поля и не сохраняет изменения
