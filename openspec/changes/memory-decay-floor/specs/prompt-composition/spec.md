# Spec Delta

## MODIFIED Requirements

### Requirement: Важность событий убывает со временем

Система SHALL уменьшать действующую важность событий на один балл за каждые N дней, где N — настройка (по умолчанию 3, 0 отключает затухание). Точка отсчёта — дата события, а при её отсутствии — дата создания записи. Действующая важность MUST NOT опускаться ниже порога из настройки (по умолчанию 1), MUST NOT превышать базовую важность и MUST NOT применяться к ядру, друзьям, семье, хобби и работе.

#### Scenario: Свежее событие выше старого

- **WHEN** два события имеют одинаковую базовую важность, но одно произошло месяц назад, а другое вчера
- **THEN** свежее стоит выше в пуле и печатается с большей действующей важностью

#### Scenario: Старое событие не исчезает

- **WHEN** событие произошло год назад при базовой важности 5 и пороге 1
- **THEN** действующая важность равна 1, и запись остаётся в памяти

#### Scenario: Факты не стареют

- **WHEN** воспоминание типа «друзья» записано год назад
- **THEN** его важность остаётся исходной

#### Scenario: Затухание выключено

- **WHEN** в настройке указано 0 дней на балл
- **THEN** действующая важность равна базовой для всех записей

#### Scenario: Порог выше единицы

- **WHEN** в настройке порога указано 3, а событие произошло год назад при базовой важности 10
- **THEN** действующая важность равна 3, а не 1

#### Scenario: Порог не поднимает выше базовой

- **WHEN** базовая важность события равна 2, а порог выставлен 5
- **THEN** действующая важность остаётся 2
