# Spec Delta

## ADDED Requirements

### Requirement: Память генерации ограничивается выбором плана

Система SHALL включать в раздел памяти промпта генерации ядро целиком и только те обычные воспоминания из топ-N, которые выбрал план. Если план ничего не выбрал или выбрал только неизвестные идентификаторы, система MUST приложить все обычные воспоминания из топ-N.

#### Scenario: План выбрал часть воспоминаний

- **WHEN** в топ-N десять обычных воспоминаний, и план выбрал два из них
- **THEN** раздел памяти содержит всё ядро и только эти два обычных воспоминания

#### Scenario: План ничего не выбрал

- **WHEN** план вернул пустой список воспоминаний
- **THEN** раздел памяти содержит ядро и все обычные воспоминания из топ-N

#### Scenario: План выбрал неизвестный идентификатор

- **WHEN** план вернул идентификатор, которого нет среди топ-N
- **THEN** этот идентификатор игнорируется; если других нет, прикладываются все обычные из топ-N

#### Scenario: Ядро всегда на месте

- **WHEN** план выбрал одно обычное воспоминание
- **THEN** ядро всё равно приложено целиком и не вытесняется выбором
