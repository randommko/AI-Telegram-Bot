# Spec Delta

## MODIFIED Requirements

### Requirement: Раздел «Промпт» показывает шаблоны разделов

Система SHALL показывать страницу «Промпт» со списком разделов в порядке сборки, и у каждого раздела MUST быть поле шаблона со счётчиком символов и кнопкой «вернуть по умолчанию». У разделов с бюджетом счётчик SHALL стоять рядом с бюджетом; у раздела «Техника» бюджет MUST NOT показываться, а счётчик SHALL показывать только число символов с нейтральной пометкой при превышении рекомендуемой длины. Для раздела персоны вместо поля MUST быть ссылка на карточку персоны, где правится её текст. Сохранённые шаблоны SHALL применяться со следующего запроса к AI без перезапуска.

#### Scenario: Список в порядке сборки

- **WHEN** администратор открывает страницу «Промпт»
- **THEN** разделы идут в том же порядке, в котором они собираются в промпт

#### Scenario: Сохранение шаблона

- **WHEN** администратор изменил шаблон раздела и сохранил
- **THEN** следующий ответ в чате строится по новому шаблону без перезапуска бота

#### Scenario: Возврат по умолчанию

- **WHEN** администратор нажал «вернуть по умолчанию» у раздела
- **THEN** в поле появляется исходный текст раздела, и он сохраняется как текущий

#### Scenario: Превышение бюджета

- **WHEN** длина шаблона превышает бюджет раздела
- **THEN** счётчик показывает превышение, а сохранение не блокируется

#### Scenario: Техника длиннее рекомендуемой длины

- **WHEN** администратор ввёл в техническую часть больше 800 символов
- **THEN** счётчик показывает только число символов и нейтральную пометку о превышении рекомендуемой длины, а кнопка «Сохранить» остаётся доступной

#### Scenario: Длинная техника сохраняется

- **WHEN** администратор сохранил техническую часть длиннее 800 символов
- **THEN** текст сохранён целиком и применяется со следующего ответа без перезапуска
