# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Реакция | `glossary/business.md` | Решение выбирает молчаливый эмодзи-отклик вместо текста. |
| Каталог эмодзи | `glossary/business.md` | Набор и тексты правятся в админке без деплоя. |
| Метка памяти | `glossary/business.md` | Вынесена за рамки решения, ставится отдельным шагом. |
| Проход чтения | `glossary/technical.md` | Отдельный фоновый компонент, запускаемый по тишине или пулу. |
| Персона | `glossary/business.md` | Характер и состояние передаются в контекст, но не меняются. |
| Эмоция | `glossary/business.md` | Остаётся за планом ответа, проход её не трогает. |
| Настройка | `glossary/business.md` | Выключатель, промпт, пул, пауза и модель читаются на каждый проход. |
| Провайдер | `glossary/business.md` | Для реакций можно выбрать другого провайдера. |
| Миграция | `glossary/technical.md` | Добавляются идентификатор сообщения, журнал, отметка и каталог. |
| Грант | `glossary/technical.md` | Новые таблицы требуют прав для бота и админки. |
