# Настройки авторинга артефактов

- **preferred-style ADR:** custom — минимальный русский ADR по `openspec/adr/ADR-TEMPLATE.md`, без пересказа контекста проекта.
- **Язык артефактов:** русский.
- **Диаграммы:** Mermaid, только если без них решение непонятно.
- **Глоссарий:** `glossary/business.md` и `glossary/technical.md`; рядом с артефактом — `<артефакт>-glossary-reference.md`.
